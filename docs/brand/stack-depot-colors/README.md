# 叠片仓配色评审

最终采用**黑底白线**，详见[最终图标](../final/README.md)。以下六组配色保留为历史候选。

形状已按反馈保留“叠片仓”。本轮仅替换线条与底色，路径、比例、8 / 256 线宽和圆角完全一致，继续保持扁平。

每组提供 SVG 和 32、48、128、256 像素 PNG；四角透明。`comparison.png` 为总览，`comparison.html` 可选择配色并查看深 / 浅背景下的小尺寸效果。正式图标已使用另行定稿的黑底白线版本。

导出：`node docs/brand/stack-depot-colors/export.mjs /工具目录/node_modules/@resvg/resvg-js`。工具只替换原 SVG 的颜色标记，不重绘图形。
