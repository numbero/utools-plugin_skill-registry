# SkillRegistory 扁平图标方案

下一轮已进一步聚焦“仓库 / 收纳容器”的含义，见[仓库语义候选](../repository-options/README.md)。

按反馈回到原图标的深底蓝线风格。本组是候选方案，尚未修改插件 manifest、侧栏或发行包。

全部使用 `#0D1117` 纯色底、`#58A6FF` 蓝色、圆角线端与 8 / 256 的统一线宽。没有渐变、光照或材质效果。SVG 为可编辑源文件；PNG 分别导出 32、48、128、256 像素，四角透明。

| 方案 | 方向 |
| --- | --- |
| 经典叠片 | 最接近原有三层菱形图标，首选保守延续 |
| 双层轻叠 | 删除一层，进一步精简 |
| 错位叠卡 | 两张正面卡片，强调可管理的 Skill 集合 |
| 同源连接 | 一个来源连接两个目标，强调共享 |
| 连环菱片 | 两个交叠的菱形，强调引用与连接 |
| 立方仓 | 等轴线框盒，强调统一中心 |

[对比图](comparison.png)包含六个方案与小尺寸预览。`comparison.html` 是可点击选择的对照视图；选择仅用于评审，不会写入插件配置。

本组为手工矢量设计，未使用图像生成。栅格化使用 `@resvg/resvg-js`；可在独立工具目录安装后执行 `node docs/brand/flat-options/export.mjs /绝对路径/node_modules/@resvg/resvg-js` 重建所有预览，不需要改变插件运行依赖。
