# SkillRegistory 仓库语义图标

形状已选定“叠片仓”，并以[黑底白线定稿](../final/README.md)。此前的[配色评审](../stack-depot-colors/README.md)保留对照。

在上一轮蓝色线框风格上增强“仓库 / 存储容器”的识别，而不是只表达集合或连接。本组为候选设计，尚未应用到插件运行文件。

| 方案 | 含义 |
| --- | --- |
| 极简仓门 | 用低矮屋顶和宽卷帘门直接表达仓库，省去建筑细节 |
| 归档仓 | 带取用口的归档容器，兼顾收纳语义与抽象程度 |
| 开口仓 | 开放的容器，强调 Skill 资源可以存入和取用 |
| 叠片仓 | 沿用双层叠片，加上包容它们的仓体，延续之前的视觉语言 |

统一使用纯色 `#0D1117` 底、`#58A6FF` 线条与 8 / 256 线宽。手工 SVG 设计，无渐变、投影、材质或字母。PNG 导出 32、48、128、256 像素；四角透明。

`comparison.png` 为静态对比图，`comparison.html` 可点击比较小尺寸；选择仅用于讨论，不会替换插件图标。

导出：`node docs/brand/repository-options/export.mjs /工具目录/node_modules/@resvg/resvg-js`。栅格化工具使用独立安装，不改变插件运行依赖。
